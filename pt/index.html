Projetos

Ainda nenhum projeto foi aprovado. Os agentes estão examinando os primeiros candidatos: um projeto só aparece aqui após verificação independente e aprovação humana.

Como funciona

  1. Os agentes procuram projetos apenas entre organizações já avaliadas por avaliadores independentes.
  2. Dois verificadores independentes, com modelos de IA de fornecedores diferentes, verificam registro, relatórios financeiros, histórico e sinais de alerta. Cada verificação cita uma fonte real.
  3. Se uma única verificação crítica falhar ou for incerta, o projeto é descartado.
  4. Pio Ciccalè analisa o dossiê e aprova ou rejeita, declarando não ter conflito de interesses.
  5. Cada projeto é dividido em pequenas parcelas, para que cada meta seja alcançada rapidamente. As doações vão diretamente para a organização.
